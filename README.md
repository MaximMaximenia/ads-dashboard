# Google Ads — дашборд по аккаунтам

Страница со сводкой по рекламным аккаунтам: расход, обращения, цена обращения,
доля показов и поисковые запросы. По каждому аккаунту отдельная вкладка.

Открыть: `dashboard/index.html` — обычный файл, открывается двойным кликом,
ничего устанавливать не нужно.

## Обновить цифры

```bash
cd 05_скрипты
python3 -I collect.py   # забирает данные из Google Ads API в snapshot.json
python3 -I render.py    # пересобирает dashboard/index.html
```

## Скрипты

| Файл | Что делает |
| --- | --- |
| `auth.py` | разовая авторизация в Google Ads API, сохраняет refresh token |
| `collect.py` | забирает кампании и поисковые запросы по аккаунтам за 7 дней |
| `render.py` | собирает HTML-страницу из `snapshot.json` |
| `ads.py` | короткая сводка в терминал |

**Все скрипты работают только на чтение.** Ничего в рекламных аккаунтах не меняют.

## Доступ

Google Ads API, версия v26, уровень доступа Explorer.
Отдельный developer token не нужен — хватает уровня доступа на Cloud-проекте.

Ключи лежат в `04_ключи/` и в репозиторий не попадают — папка в `.gitignore`.
Без них скрипты не запустятся; авторизацию нужно пройти заново через `auth.py`.

## Чего здесь нет

Статистики аукционов — списка конкурентов и их доли показов.
Google не отдаёт её через API, она есть только в интерфейсе.
